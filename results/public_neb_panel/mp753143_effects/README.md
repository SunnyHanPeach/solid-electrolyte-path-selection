# mp-753143 外部收益的家族与能量剖面审计

复用此前已冻结的 62 条 FP-DeErr 路径、42 个结构家族、五个种子和三臂逐图像能量。[原始配对评分](../mp753143_b2/README.md)仍是主结果。本次分解和敏感性分析沿用该面板、门槛和训练配置。

## 家族收益

相对 Replay，19 个家族在五个种子上均改善，11 个家族在五个种子上均退化，其余 12 个家族未呈五种子同向。收益排名前三的家族贡献了有符号总净收益的 51.9%，占所有正贡献的 33.6%。事后移除这三个家族，家族等权净收益由 +0.353 降为 +0.183 meV。原面板保留全部家族。这一敏感性结果说明收益有一定集中度，离开这三个家族后平均收益方向仍为正。

相对纯 D₀，14 个家族在五个种子上均改善，9 个均退化。移除此对照下收益最高的三个家族后，平均绝对收益由 +0.088 变为 −0.007 meV。两种对照各自按收益排序，前三名单可能不同。这些结果支持保留绝对收益未决的判定。

## 能量剖面

按各自起点将每条轨迹的总能量转为相对能量，分别计算参考 DFT 最高能量图像、其他内部图像和终点的绝对误差。三处指标均按种子与结构家族等权汇总。初始图像的相对能量固定为零。所有 62 条参考路径的 DFT 最高图像均在内部。

| 量 | 相对 Replay 的收益（meV） | 相对纯 D₀ 的收益（meV） |
| --- | ---: | ---: |
| 模型各自取峰后的能垒 | +0.3527 | +0.0875 |
| 固定 DFT 峰位的相对能量 | +0.3542 | +0.0761 |
| 两种取峰口径的收益差 | −0.0015 | +0.0114 |
| 其他内部图像的相对能量均值 | +0.1293 | −0.0059 |
| 终点的相对能量 | +0.0398 | +0.0197 |

Path 与各对照臂之间的模型最高图像均未更换（各 0/310 个路径–种子配对）。这并不要求模型峰位与参考 DFT 峰位一致，因此两种取峰口径仍可得出略不同的收益。相对 Replay 的改善主要体现在 DFT 峰位相对起点的能量差。能量差分不能识别起点与峰位对这一变化的各自贡献，也无法仅凭这批能量预测判断迁移 Li 的力误差是否改善。

本轮审计没有检验新试样筛选策略。Activation 或其他特征的增量，应以冻结的共同候选库、实际 DFT 预算与最终未见材料能垒 MAE 评价。
