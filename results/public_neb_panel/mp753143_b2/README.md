# mp-753143 五种子外部配对结果

在 62 条 FP-DeErr 路径、42 个结构家族上，五个种子的 Path 都优于等曝光回放。净收益为 **+0.353 meV**，95% 区间为 **[+0.062, +0.666] meV**。区间下限未达到预定的 +0.25 meV。Path 相对纯 D₀ 的绝对收益为 **+0.088 meV**，区间为 **[−0.078, +0.269] meV**。正绝对收益仍未确认。

| --- | ---: |
| 纯 D₀ | 121.879 |
| 等曝光回放 | 122.144 |
| mp-753143 Path | 121.791 |

| 种子 | 相对 Replay 净收益（meV） | 相对纯 D₀ 绝对收益（meV） |
| --- | ---: | ---: |
| 17 | +0.450 | +0.091 |

净收益在 26/42 个家族、39/62 条路径上为正。逐家族留一后的总体净收益为 +0.260 至 +0.400 meV。移除潜在重复跃迁 `147920|10` 后，净收益为 +0.353 meV，绝对收益为 +0.087 meV。区间条件于五个固定种子。历史 107 材料面板上同批模型的净收益为 +1.16 meV；本面板方向一致，点估计较小。不同面板的点估计未进行直接的差异检验。

实际训练构型复核覆盖 278 个 D₀ 构型和 mp-753143 的 5 张训练图像，未发现与 62 条公开路径的匿名骨架重叠。15 个检查点与训练归档核对一致。Path 和 Replay 采用 735 步和匹配的原子曝光，纯 D₀ 保持原有 710 步。两种训练硬件的区别详见[评分协议](../mp753143_protocol.md)。本次在同一台 CPU 上完成 6,510 次图像推理并独立复算收益和区间。总耗时约 14 分 29 秒。

这些结果支持将 mp-753143 保留为有外部净收益信号的对照案例。等 DFT 预算下的选样效果仍需比较独立候选组合。当前外部指标是固定参考几何能垒误差，适用范围见[面板说明](../README.md)。
