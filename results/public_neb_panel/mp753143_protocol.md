# mp-753143 在 FP-DeErr 上的外部配对评分

使用已归档的 B2 `path1`、`replay1` 和 Phase 1 纯 D₀ 的 17、29、43、53、67 五个种子。追加对象固定为 `mp-753143_5_13_0_0_0`。Path 与等曝光 Replay 都在 B2 的 RTX 2080 Ti 上训练 735 步。纯 D₀ 复用 B2 已认领的 RTX 4090 上的 710 步权重。所有模型在同一个本机 CPU、同一 FP64 推理口径下评分。由于先前的公开纯 D₀ 演示使用 A1/B5 的另一个检查点，此处重新推理每个种子对应的纯 D₀。

从已冻结的 FP-DeErr 面板出发。对 278 个 D₀ 构型和新增路径的五帧再次检查去 Li 匿名骨架重叠。筛查在读取模型评分前固定，检测到命中时从全部训练臂一致排除。对每条路径保留原始 DFT 图像顺序，模型与参考各自以最高图像的能量减起点能量作为正向能垒。家族内平均路径误差，再按家族等权并对五个种子等权平均。

- 净收益为 Replay 的 MAE 减 Path 的 MAE。
- 绝对收益为纯 D₀ 的 MAE 减 Path 的 MAE。
- 95% 区间采用 20,000 次配对家族重采样。区间条件于这五个固定种子和当前参考面板。
- 沿用 +0.25 meV 的实用门槛。确认正收益需区间下限大于 +0.25 meV、五个种子均改善、逐家族留一后改善仍为正。
- 主分析保留 `127400|8` 和 `147920|10`。另报告去掉后者的敏感性结果，保留规则在看分数前按路径 ID 固定。

结果只检验这条路径和当前训练配方在公开 DFT 固定几何上的收益转移。训练新增路径的成本、选样策略差异和每个模型重新优化 NEB 的误差需要各自验证。材料独立性限于项目训练记录和结构重叠筛查的范围。
