# B5-R 独立评估面板可用性

**主评估面板尚未放行。** 需要分别建两份清单。候选路径取得完整能量和力标签后用于更新 MACE。目标评估材料提供未参与训练、方法选择和路径排序的可比 DFT 能垒。

| 来源 | 现有资产 | 本轮结论 |
| --- | --- | --- |
| LiTraj nebDFT2k | 历史有初始与 DFT 弛豫轨迹和能量标签。既有台账显示非封存材料几乎已用完 | 继续用于开发复算。4 个独立 Test 材料保持封存。 |
| LiTraj nebBVSE122k / BVEL13k | 结构、迁移端点和低保真 BVSE 数据 | 可构建候选池。MACE 更新还需完整路径的 DFT 能量与力。 |
| 本地文献能垒数据 | 619 条有初末结构和文献能垒的数据，标签的计算参考混合 | 42 条 GGA 记录通过同序同晶胞、Li 独立位移与精确元素体系隔离的粗筛，覆盖 22 个精确体系、13 种 BibTeX 字符串。 |
| OBELiX、SAI-MAT | 前者提供实验电导率和结构元数据，后者现有两种材料的 VASP NEB 档案 | OBELiX 主要用于结构来源。SAI-MAT 用于计算接口和对照核验。 |

本地公开数据的 619 条与 2026 年论文中描述的数据规模一致。用 PBC 核对初末态的方法保守识别了 152 条 Li 跃迁候选，其中 127 条标为 GGA。再排除与历史 LiTraj 记录和 B5-R 新候选重合的精确元素集合，剩余 42 条。此处使用的是结构和来源元数据。计算参考只提供 GGA 大类，仍需逐条核对泛函、赝势、赝势价态、空位条件、NEB 方向、能垒定义及收敛。公开数据中的构型是端点，当前缺少同一 DFT 跃迁的完整路径或经过交叉验证的替代几何，无法直接按项目的逐图像能垒 MAE 协议评分。[本地预筛证据](evaluation_asset_audit.json) · [原始文献数据](https://www.nature.com/articles/s41597-025-06196-x) · [619 条数据的方法说明](https://www.nature.com/articles/s41524-026-01972-8)

下一次前瞻决策前，从 42 条中核对可找回完整图像的文献条目，逐条相对候选集合、D₀ 和历史开发集查晶体与迁移环境近重复。冻结独立评估面板和真实 DFT 核时口径后，再解封该面板用于最终评分。历史 4 个 Test 标签未读取。[既有项目审计](../../docs/path_selection_blind_preflight.md) · [LiTraj 数据资产](https://github.com/AIRI-Institute/LiTraj#available-datasets-and-source-links)
