# B5-R Activation 实现核对

核对 Varga-Umbrich 等的 arXiv v1 §3.2.1、§3.3 及附录 A、C.4。论文报告的是分子反应体系中构型级主动学习。本项目检验的是固体完整迁移路径的训练收益与选样规则，路径池化和参考库定义是本项目的扩展。[论文与附录](https://arxiv.org/html/2605.03964v1)

| 项目 | 论文定义 | 项目实现 |
| --- | --- | --- |
| 提取层 | 两层相互作用后的原子隐状态 | MACE 0.3.14 的 `node_feats`，对照同模型 `get_descriptors`，取相同两层 |
| 标量通道 | 每层 $L=0$ 的 128 通道 | 同样提取 128 × 2，保留拼接顺序 |
| 原子池化 | 对结构内全部原子取均值，拼接两层 | `activation_full` 沿用算式。A1 的 256 维缓存只取迁移 Li，沿用 `activation_li` 名称 |
| 模型 | SPICE 2 预训练 MACE | 项目已审计的 D₀ seed-17 MACE-MP-0 Small 微调权重，SHA256 固定。相同公式的固体适配 |
| 归一化 | 用带下限的向量 L2 范数归一化 | 原子和图像池化后对路径向量归一化。保留逐图像向量 |
| Activation Distance | 特征向量间距离可由核导出 | A1 参考覆盖用 $1-k$。本轮最远点和 LCMD 采用 $d_k^2=2-2k$ |
| Activation Kernel | L2 归一化后点积 | 每种路径池化独立生成 $K=ZZ^\top$，检查正半定性 |
| Posterior Variance | 用已标记集和已选样本条件化高斯协方差 | 相同条件化公式，$\lambda=10^{-3}$。参考为每个 D₀ 材料首帧，共 50 帧。选样每步加入新选路径，未做残差方差的校准 |
| LCMD | 将候选派给最近中心，按簇平方距离和选簇，再选簇内最远点 | 公式相同，中心为 D₀ 参考和已选路径，输入为路径级核 |
| SOAP | 6 Å、$n_\max=8,l_\max=6$，外层平均 | 沿用 A1 固定参数和元素压缩，另计算所有原子功率谱的平均与迁移 Li 版本 |

当前公开论文正文支持算式级核对。此次未取得作者运行代码或同一训练集的核矩阵对照。与 A1 的等价性由同一权重、逐图像迁移位点的缓存复算验收。B5-R 的高分位数与共同五点网格拼接均作为敏感性分析，Mean 为主。历史收益预测只拟合冻结的浅层统计基线，MACE 未训练。[A1 实现](../../src/phase_a1_descriptors.py) · [B5-R 提取](../../src/extract_phase_b5_r_features.py) · [选样和收益比较](../../src/analyze_phase_b5_r.py)
