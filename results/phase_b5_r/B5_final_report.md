# B5-R 独立候选选样准备

2026-11-26

**可以冻结候选排序作前瞻准备，暂不建议投入新的 DFT 预算。** 实现、候选重建和排序已核验。历史结果显示 Activation 核对路径收益幅度有探索性信号，但按阴离子家族留出时无法稳定排序。主规则的前 5 条候选也没有因加入 Activation 改变成员。独立评分面板与实际计算预算仍待锁定。

## 主要证据

- 在 2,647 个预筛材料中按冻结元数据规则排队，重建并纳入 24 条新路径，覆盖卤化物 10 条、硫化物 6 条、氧化物 3 条、复合和其他 5 条。每条包含 5 张有序的 BVSE 预处理图像。扫描到 867/867 个历史材料的母晶胞，并用匿名约化计量、空间群和阴离子做粗家族排除。该代理能排除直接重合，完整结构和局域环境的近重复仍需逐项复核。[预筛规则](protocol.json) · [候选审核](candidate_selection_audit.csv)
- 计算 78 张历史图像、120 张候选图像和 50 张 D₀ 参考帧的四种表示。以图像均值为主，逐图像反应坐标、P90 与五点插值拼接保留用于复算。全结构 Activation 与论文的标量池化算式一致，模型权重与应用对象属于本项目。旧版 Li-centered Activation 与 SOAP 的历史缓存通过数值复核并复用。[方法核对](literature_reproduction_audit.md) · [复核清单](manifest.json)
- 云端同批 16 图像的 CPU 与 GPU 特征最大相对 L2 差小于 7×10⁻¹⁶。Batch 1 实测 GPU 1.55 s、云端 4 线程 CPU 2.66 s。GPU 的 Batch 2、4、8 触及为 QE 留出的 PyTorch 分配上限。全量 Activation 改用云端 CPU，248 张图像用时 54.0 s，SOAP 用 8 个 CPU 工作线程。计时处于 QE 并行运行条件。[计时实测](compute_benchmark.csv)

## 历史收益幅度与排序

这是 14 条历史路径的开发对照。每条路径只贡献一个训练收益标签，沿用 B2 的 17、29、43 三种子与 107 材料面板。对照包含最短 Li 接触、阴离子家族、图像数、训练步数和原子监督曝光。逐折标化仅用该折训练路径。表中为 Mean 池化对应的留出预测 MAE，单位为 meV。

| 方法 | 逐路径留一绝对 / 净收益 | 留阴离子家族绝对 / 净收益 |
| --- | ---: | ---: |
| 训练折均值 | 3.93 / 4.05 | 3.66 / 3.86 |
| SOAP 新颖性 | 3.62 / 3.66 | 4.17 / 4.38 |
| SOAP＋Activation 新颖性 | 3.94 / 3.95 | 4.32 / 4.51 |
| SOAP 核回归 | 3.66 / 3.71 | 3.92 / 4.14 |
| Activation 核回归 | **2.60 / 2.63** | **3.47 / 3.70** |
| 等权合并核回归 | 3.06 / 3.10 | 3.64 / 3.86 |

同一回归形式下，Activation 核降低了历史逐路径留一的幅度误差。留阴离子家族后，它的 Spearman 相关为 **−0.34 / −0.14**，MAE 对均值基线的优势缩小到约 0.20 / 0.16 meV。合并核的幅度误差介于两个单核之间；直接合并两个新颖性分数反而提高了误差。当前证据支持将核表示保留作对照，尚不足以指导跨家族训练价值排序。类别覆盖度、统计不确定性和 14 条标签的历史使用限制均保留。[逐折预测](historical_utility_analysis.csv) · [方法汇总](feature_comparison.csv) · [图](figures/historical_utility_mae.png)
