# H2 · 公开路径复用与已有 QE 成本归并

## 公开数据可以怎么用

本机归档的 nebDFT2k 有 867 个材料、1,681 条路径，每条均能找到初始和 DFT 弛豫文件。与 D₀ 有 50 条路径 ID 完全相同。H1 的 24 条候选和 QE-a 材料未在该归档按材料 ID 命中。ID 筛查仅用于定位已有标签，结构近重复沿用 H2 独立审计。验证与测试部分仅盘点索引和文件名。 [LiTraj 公开资料](https://github.com/AIRI-Institute/LiTraj)

逐帧复算全部 **1,220 条公开训练路径**，索引 `em_dft` 在数值精度内始终等于**整条曲线的最大能量减最小能量**。以首张图像为零的 A→B 能垒仅有 670 条与索引在 1 meV 内一致，以较低端点为零的定义有 1,033 条一致。以后需要 A→B 能垒时，直接用逐帧能量减首张图像并取最大值。核对了 B2 标签冻结与 FP-DeErr 配对评分的实现，两处已按首张图像起算。 [B2 真值读取](../../src/audit_signed_barriers.py) · [外部评分实现](../../src/score_public_neb_pair.py)

取得 MPLiTrj 官方子样本的完整**训练成员**，解压字节数和 ZIP CRC 均一致。逐帧核验 **94,044 个构型、1,009 个材料**的头部，均有能量、力和应力字段。另用 ASE 读取首段 1,033 帧，逐帧确认标签数值有限且全原子力形状正确。训练成员有材料 ID，未见路径 ID、图像编号、离子步数或作业计时。607 个材料与 nebDFT2k 共享材料 ID，其中 240 个在 nebDFT2k 有多条路径。该成员可用于材料级监督和按家族去重，逐跃迁回测需从 nebDFT2k 或另有原始路径映射的资源取标签。预先封存的评价数据本轮没有解封。 [MPLiTrj 数据说明](https://huggingface.co/datasets/AIRI-Institute/LiTraj) · [审计明细](public_data_reuse.json)

## 已有成本及下一次采购的放行条件

原账本 23 个作业事件加上四个网格或截断能验证事件，共 27 个。按硬件分别记录 solver 墙钟、GPU 占用与已知 MPI 核时。试验前退出与实际执行分开记。RTX 3090 对 QE-a 在 2×2×2、50/400 Ry 下的四次固定几何求解为 **44.25–87.22 分钟/次**，其中一次仅验证 SCF 与力、波函数输出不完整。它们属于同一材料的参考范围。mp-5012 的 11.08 MPI rank·h 是一次中断的 CI 段，保留原口径。 [成本汇总](recorded_costs.json) · [写盘对照](../phase_b4_r2/io_k222/report.md) · [mp-5012 CI](../dft/mp5012_ci/README.md)

24 条 H1 候选有 55–175 个原子，其中 12 条暂按 3×3×3 网格代理估计，2 条为 2×2×2。网格代理未经过逐路径 QE 验收。QE-a 的完整成本、B 端点和后续路径优化仍待作业账本确认。当前仅可将同机同协议的固定几何耗时用于粗范围估计，不能外推出单条路径总时长、候选池失败率或最终预算。保留前瞻协议中的实际采购计时规则。若入选组合在合理范围内不变，直接沿用已有标定。只有范围跨越准入边界时，才对会改变采购决策的候选安排短测。[前瞻规则](../phase_h2_preparation/prospective_protocol.md)

云端只读检查未通过 SSH 认证。QE-a 的最新本地可核验证据是启动报告和历史验收快照，现场进度及端到端计时未获得。本轮没有向远端写入或提交算例。
