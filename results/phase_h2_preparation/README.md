# Phase H2 · 公开轨迹追溯与前瞻规则

## 独立评价材料

已把 H2 审计的 18 条 PBE 记录逐条对应到七个作者来源和具体文件入口。八条在先前稽核中没有骨架命中，作为优先追溯对象。其余十条保留复核记录，需确认骨架相似是否影响正式分组。原先的 42 条审计和 FP-DeErr 外部评价继续分别归档。

这一轮实际取得并检查了两份原始文献文件。ACS Figshare 为 Xu 论文列出一个 32 页补充 PDF，文档包含 AIMD 图、结构和扩散对照，未找到四条目标 CI-NEB 跃迁的完整有序坐标。Zhang 的 APS 接收稿可读，能核对 CI-NEB 方法和 Li₃OBr 路径讨论，仍缺两条目标跃迁的原始图像及逐图像能量文件。两份 PDF 均无内嵌附件。 [Xu 附件](https://doi.org/10.1021/acsami.8b12026.s001) · [Zhang 接收稿](https://link.aps.org/accepted/10.1103/PhysRevB.87.134303)

Xiao 原文指向 Table S1 的 BV/DFT 能垒对照。Kim 的论文说明 Li₃SeCl 有多条非等价跃迁和多个迁移机制。只有材料组成及能垒值时无法确定原始跃迁身份。其余来源的附件可达性和原始文件缺口见逐来源账本。[Xiao 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4585693/) · [Kim 作者稿](https://public.websites.umich.edu/~djsiege/Energy_Storage_Lab/Publications_files/JMCA_anti-perovskites.pdf) · [追溯账本](pbe_trace.csv) · [来源证据](source_followup.csv)

**本轮主评价放行新增 0 条。** 公开证据仍不足以匹配完整有序轨迹、迁移方向及对应的 DFT 能垒。FP-DeErr 可继续用于已冻结的固定几何外部评价。

## 前瞻协议

已写入共同候选池、结构隔离、六种基线、配对种子、统一购置顺序、失败与续算记账规则和最终评价。正式执行清单等待主评价面板、候选结构放行和实测成本，届时固定预算数值后才能启动新采购。[前瞻选样规则](prospective_protocol.md)

用 B5-R 保存的 Mean 排序复算了 SOAP 与 SOAP＋Activation 的所有等条数前缀。排除 H1 已标记的四条结构重复候选后，前 **5、6** 条的两个集合仍完全相同。前 **1–4** 条均有集合差异。这个复算过滤了既有排名，未重新拟合或运行 k-center。真实 DFT 成本不同，仍需按统一预算重新确定可采购集合。 [集合对照](h1_prefix_overlap.csv) · [输入哈希](audit.json)
