# Phase H2 前瞻选样预注册

## 主问题与评价

在相同实际 DFT 预算下，按 DFT 前信息选择路径，能否降低未见材料的正向迁移能垒 MAE？并行检验相对纯 D₀ 的绝对改善，以及相对有竞争力选样基线的优势。等曝光 Replay 作为训练归因对照，按各已采购组合匹配插入位置、更新步数和监督曝光。复用冻结的 MACE-MP-0 Small 初始化与 Recipe A，候选数据弛豫后的几何、真实能量、力和实际训练收益均不参与排序。训练采用配对种子 17、29、43，所有策略及纯 D₀ 使用同一版本和硬件。评价采用同一参考轨迹与起点，先聚合路径和种子结果，再对结构家族等权。在各比较中配对重采样结构家族，并单列三个种子。使用既有 +0.25 meV 作为历史实用参考线，正式面板的精度和主比较判定在执行清单签发前固定。

每个预算点的策略臂共用保护式 D₀ 排程和固定总更新数。执行清单预留能容纳该预算点允许采购组合的插入位，沿用 Recipe A 的监督剂量。未使用的插入位用 D₀ 回放填充。实际购得的图像和监督原子数随 DFT 预算与路径组合变化，单列报告。纯 D₀ 保留原训练排程作为不追加数据的基准。

主评价面板的每条记录必须有完整有序图像、正向参考能垒及轨迹与原文的对应证据。核查泛函、赝势、空位、自旋和收敛口径。VASP 与 QE 同属 PBE 并不足以判定标签可直接合并。做跨口径比较时分别报告，统一协议的 QE 标签与经同口径验证的数据单独锁定。FP-DeErr 已有固定几何外部分数，可作为独立报告的外部面板。此前已用于机制审计的部分不得据此调整主分析规则。四个封存测试材料的标签留待原封存流程。若现有的完整公开轨迹不够，优先补齐独立评估家族的标签，评价采购开销单列。

## 候选池与策略

扩池到一个共同的 DFT 前候选库。先按材料 ID 保存资格账本，核查母晶胞近重复、路径端点与迁移 Li 的周期映射。同母体或非 Li 匿名骨架通过既有周期匹配的材料归入同一结构组，按组隔离历史开发、D₀、候选和最终评价。对径向或 Li 局域 SOAP 相似标记复核原始端点与迁移通道。入池规则以数据可恢复性、化学覆盖、几何健康和原始家族隔离为依据。先锁定全集和排除记录，再计算比较策略，扩池时禁止按 SOAP 与 Activation 的名次差捞样。`mp-1191903` 单列工程试点。

| 策略 | 固定排序口径 |
| --- | --- |
| Random | 首个排序按 `SHA256("h2-random-01" + "/" + edge_id)` 由小到大。若预算允许预注册随机重复，使用同一规则的 02、03 等编号，并在首批采购前锁定重复数。 |
| BVSE | 沿用 B5-R 的正向 BVSE 能垒低值优先。 |
| D₀ 覆盖度 | 路径 SOAP 与已有 D₀ 的最近邻相似度低值优先，参考集固定。 |
| SOAP（多样性） | 沿用 B5-R 的平均池化全结构 SOAP 核和 k-center。每轮根据 D₀ 及已选路径的覆盖更新排序。 |
| SOAP＋Activation | 复用相同 k-center，输入为既有归一化 SOAP 核和 Activation 核各 0.5。 |
| Model Disagreement | 使用 B0 已核验的三个 D₀ 模型，按初始路径上预测正向能垒的样本标准差从高到低。 |

同分按完整 edge ID 排序。训练剂量匹配规则和任何剩余控制参数需要进入最终执行清单。SOAP 参考距离排序和贪心 SOAP 多样性是两种明确不同的策略。Activation 的独立贡献用相同购置规则下 SOAP 对比 SOAP＋Activation。预算点的可购置集合完全相同时，该点对选样增量的实证对照为零。永久保存这些预算点。

## 预算与采购

1. 在同一硬件与资源配额下按 QE 作业实际占用时长记主账，另记 CPU 分配核时、GPU 占用小时和费用。对不同硬件单列结果，混合采购需先固定可复核的共同成本单位。
2. 生效清单必须给出各预算点数值、每条路径的成本预估、单任务上限和统一续算策略。所有策略共用同一版成本表。现阶段仅有部分 SCF、端点或 CI 样本，首条完整路径用于成本标定。可在同一硬件上继续用其他合格体系的短测检验外推。禁止通过名义图像数或原子数冒充实测核时。
3. 各策略在首批采购前签发候选顺序和候补顺序。根据预算余量和统一的费用上限按序准入，未用余额如实记账。某个任务触及上限时保存失败或断点，已用成本照计。是否续算和是否切下一候补，根据冻结的可验收状态和剩余成本处理。成本包含端点、常规 NEB、CI、准入要求的数值验收、失败与重启。训练资源另列。
4. 多策略购置同一路径时，真实项目总账去重，每个策略账本都扣除该路径独立执行需用的成本。全池先标注的比较使用离线反事实结果和完整采集总账，真实前瞻采购以采集前锁定的策略为准。纯 D₀ 为零新增 DFT 对照。

## 发布条件

正式购置前保存训练与评价家族清单及哈希、候选全集与冻结排名、每个预算点预购置集合、统一成本预估与耗时上限、共同训练配置、主比较和区间口径。候选和评价同家族重叠必须解决。用已有 24 条候选重放的等条数审查只用于确认 Activation 在何处有集合差异。首条 QE 工程试点的实时续算、日志及停止条件沿用原归档。本记录冻结可提前确定的规则，具体预算数值、最终评价样本和扩池后排序待签发生效清单。
