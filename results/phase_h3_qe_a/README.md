## 补录与预算判定

每次独立尝试保存阶段、启动与停止时点、退出原因、求解器墙钟、MPI ranks、每 rank 的线程数、GPU 数和占用时长。核对输入与重启状态身份、结束日志、XML 能量与力，以及普通 NEB 和 CI 中各图像的有效更新。重复写出的迭代按段和检查点关联，失败段消耗照计。可直接续接的有效计算归属原阶段，丢弃的重复计算与恢复开销单列，阶段总账按实际尝试逐段求和。作业占用成本和实例账单分别记录，现有快照不足以恢复后者。

先以实测替换端点、普通 NEB 和 CI 对应分量，保留缺项的显式假设。实际成本落位后，在同一预算和冻结排序下做 ±20% 与 ±30% 敏感性分析。共同偏差用于测整体预算标定风险，逐候选偏差用于测边界路径排序、集合重合和超预算风险。先看这些变化是否会让对照集合失去可比性，策略性能以独立面板的正向能垒 MAE 判定。主要决策不受这些扰动影响时，已有标定即可支持采购放行，无需等待所有候选成本精确。

实际采购清单仍待 QE-a 阶段日志与合格主评价面板。两项准备可并行，物理输入、收敛门槛与首条路径范围按原计划执行。
