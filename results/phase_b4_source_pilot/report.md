**完整结构库已恢复。2,647 个预筛材料全部有母晶胞和带质心的跃迁记录。** 对前次冻结的三个材料运行短程松弛，三条达到 BVSE-NEB 力残差阈值，两条带有高于端点的内点峰。该测试解决数据入口和短程几何预处理问题。正式家族划分、真实 DFT 能垒及路径训练收益仍待验证。

## 完整结构核验

从 LiTraj 官方来源恢复 BVEL13k（10,711,383 字节）和 nebBVSE122k（199,873,007 字节）。两包与原有本地前缀和目录尾段逐字节一致，全包 CRC 校验通过。扫描了 12,807 个母晶胞记录、122,421 个质心记录。16,155 条预筛跃迁全部能按 edge ID 找到质心，并按材料 ID 找到母晶胞。这个数字衡量数据覆盖，正式几何映射仅对试测的三个材料逐一验收。见 [校验记录](archive_integrity.json) 和 [覆盖统计](coverage.json)。 [LiTraj 官方数据源](https://github.com/AIRI-Institute/LiTraj#available-datasets-and-source-links)

## 执行记录

两包扫描以两个线程并行，三条路径分别占用三个并发工作线程，另将底层线程限制为 2。验证 MACE 特征时使用 4 个 CPU 线程。全包索引匹配实测约 11.5 s，三路预处理实测约 2.76 s。三条超短任务的串行单路径计时合计约 2.12 s，本次未观测到加速。较大的 CPU 批次默认并行并根据短测调整并发数。复跑入口为 [本轮代码](../../src/run_phase_b4_source_pilot.py)，参数依次为母晶胞 ZIP、质心 ZIP、低保真索引、历史索引、三候选清单和新的本地输出目录。并发数可用 `--workers` 指定，运行版本见 [结果记录](bvse_pilot.json)。

现有 [mp-5012 QE 试点](../dft/mp5012_ci/manifest.json) 只核验了 Li、O、Si 三种赝势及其散列值。两条有内点峰的试测路径新增 As、V、In、S 等元素，端点、磁性或电子占据设置及与历史 DFT 数据的相容性仍需锁定。此次只做了 CPU 结构恢复、预处理和特征检查。原始档案、临时几何、检查点及四个封存测试标签保留在本地，本轮没有启动 DFT 或模型训练。
