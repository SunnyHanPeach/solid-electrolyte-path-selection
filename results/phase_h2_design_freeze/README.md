# 固定 DFT 预算的前瞻策略比较

## 候选、基线与评分

沿用 B5-R 的 24 条原候选及 H1 的四项结构排除，保留 20 条供模拟。候选选购只用已有的 DFT 前特征。Random 使用固定 SHA-256 顺序，历史参照另运行 256 个预设随机序列。BVSE 按低能垒排序，D₀ 覆盖按距既有参考库的最近核相似度从低到高排序，Model Disagreement 按三个基础模型的正向预测能垒样本标准差从高到低排序。SOAP 和 SOAP＋Activation 复用 H2 的 k-center 规则，组合核等权。并列按路径 ID 排序。对照优先检验 SOAP＋Activation 相对 SOAP 的增量，另报告与 Random、BVSE、D₀ 覆盖和模型分歧的比较。

正式评价先冻结 D₀ 数据、MACE 初始化和训练配方，所有策略使用相同的训练更新预算、种子 17、29、43 及同协议的等曝光 Replay。主指标为独立评价面板的正向能垒 MAE，正向能垒定义为路径最高预测能量减初态预测能量。按事前冻结的材料家族先算家族内平均，再对家族等权汇总。以材料家族为单位配对重采样 10,000 次，区间条件于三个固定种子，同时逐种子报告。比较某策略与对照时，收益为对照 MAE 减该策略 MAE。沿用 0.25 meV 的实用门槛，确认改善需家族配对区间下限高于门槛且三个种子同向。纯 D₀ 给出绝对收益，等曝光 Replay 给出净收益。主要增量对照及两个收益分开判定，其他基线逐项报告。

候选训练路径与最终面板按母结构家族隔离。LiTraj 已用材料只参与开发和离线回放，FP-DeErr 维持外部固定几何用途，协议试点仍排除在确认性面板之外。回放只读取已有 B2 归档收益表和特征，四条封存标签不参与。

## 预算扣减

66.83、133.67、267.33 小时保留为规划预算。正式采购上限待同一 QE 资源配置的端点、普通 NEB、CI-NEB 成本与独立面板资格核验后签发。实际比较在同一资源配置以分配的求解资源计量，单 GPU 用 GPU 小时、CPU 用分配核时，两者及实例账单分别登记。每条候选的 DFT 准入短测、端点、普通 NEB、CI-NEB、失败及重启都归入该路径实际成本。

每个策略依规则选择当前预算可负担的最高优先级路径。准入时从其剩余额度预留该路径上限，分段续算不得超出预留量。预留下限由全流程成本标定和预设分段上限定出，所有策略共用成本表。任务停止后扣实际支出并退回剩余预留，失败支出照扣。候选放行、失败及预算不足全部登记。不足以容纳任何剩余候选时结束该策略。同一条路径可共用一次物理计算，但各策略账本均扣全额。若两个策略选择完全相同的训练路径集合，则复用配对训练，记录该预算点没有选择增量。

## 离线预演

先以已有 H2 的低、中、高成本复现全部 54 项原始采购，再在中档模型上对共同成本偏差及逐候选偏差做 ±20%、±30% 压力测试。逐候选扰动使用 128 个冻结 SHA-256 情景，共用成本扰动便于配对。扰动区间是设计输入。

历史收益回放限定为 14 条同协议 B2 路径上的单路径选择。先锁定每个策略的选择，再接入已测量的绝对、净收益标签。用已有单路径结果检验选择规则的行为，组合收益需实训确认。历史结果不会修改候选排序、基线或效果判定。
