# BVSE 几何筛查阈值敏感性

在同一批 15,516 条已经审计的路径上固定 0.10 eV/Å 的残余力要求，只改变最终 Li 最短接触和内部峰高出端点的阈值。图中白框为原筛查使用的 1.4 Å 和 0.02 eV。材料内先汇总路径通过率，再对材料等权平均。

在内部峰差保持 0.02 eV 时，接触阈值从 1.3 Å 收紧到 1.5 Å，初始短接触组的材料等权通过率从 79.9% 降到 68.5%，其他路径从 86.5% 降到 82.5%。固定 1.4 Å 时，将峰差从 0.02 eV 提到 0.05 eV，两组通过率分别下降约 0.45 和 1.31 个百分点。接触要求是这批候选的主要敏感因素。

24 条冻结候选在原阈值下全部通过。在 1.5 Å 和 0.02 eV 下通过 21 条，在 1.5 Å 和 0.05 eV 下通过 20 条。敏感性分析沿用预先冻结的候选名单和所有原排名。该结果供设定正式计算前的几何复查优先级。
