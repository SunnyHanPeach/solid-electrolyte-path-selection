# B4-Bridge-01 固定几何桥接与数值收敛复核

2026-11-26

**五张图像通过预设桥接门槛。** 同一条已公开的 Li–O–Si 路径上，QE 与 LiTraj VASP 的最大相对能量偏差为 **4.82 meV**，最大全原子力分量 RMSE 为 **0.0139 eV/Å**，两者峰值均在图像 3。阈值为相对能量最大偏差 10 meV、逐图像力分量 RMSE 0.02 eV/Å。结论适用于本条固定几何路径。

## 15 分钟复核

固定图像 0 与 3，每组只改一项数值设定，并用同一云端 QE 二进制和赝势。逐项重建输入并复核哈希。对照比较端点到峰区的相对能量，以及两张图像各自的全原子力分量 RMSE。 [数值复核明细](numeric15_scores.json)

| 对照 | 端点到峰区相对能量变化，meV | 最大力 RMSE，eV/Å | 两张 GPU 秒 |
| --- | ---: | ---: | ---: |
| 截断 50/400 → 62.5/500 Ry | −0.193 | 0.00125 | 375 |
| 高斯展宽 0.10 → 0.05 eV | −6.298 | 0.00383 | 336 |

四次 SCF 全部收敛。按高斯零展宽估计复核，两个能量变化分别约为 −0.192 meV、−4.925 meV。两项均通过本轮数值差异阈值。50/400 Ry 足以作本条路径的起始配置，桥接比较继续沿用历史 0.10 eV 展宽。网格加密、自旋、候选元素的赝势和 NEB 收敛仍需在正式候选上核验。

## 资源与结论范围

- 单张 RTX 3080 Ti，QE 7.3.1，单 MPI 进程、2 个 OpenMP 线程，图像依次运行。五图像合计用卡 **12 分 58 秒**，数值复核 **11 分 51 秒**，合计 **24 分 49 秒** 求解时长。数值复核期间显存峰值采样约 9,726 MiB。上述用卡时长不含环境准备、传输和云端空闲计费。
- 本机 CPU 两路按要求中止，合计消耗约 8.63 分配 rank·小时。CPU 未完成同图像 SCF，现有记录支持实际端到端提速，硬件和 QE 版本的独立贡献需要额外对照。 [运行与成本清单](run_manifest.json)
- 本轮支持该路径的相对能量和力比较。Li 赝势价电子数差异、不同化学体系和绝对能量口径仍保留为独立问题。四个保留材料继续封存。本轮未做新候选 DFT、NEB 或模型训练。
- 评分入口为 [固定几何桥接评分](../../src/score_phase_b4_bridge.py)。输入为历史 ZIP、桥接清单、逐图像目录及输出 JSON 路径。GPU 版本与镜像架构、二进制和输入哈希已记录。 [NVIDIA QE 镜像](https://catalog.ngc.nvidia.com/orgs/hpc/-/containers/quantum_espresso/-)
