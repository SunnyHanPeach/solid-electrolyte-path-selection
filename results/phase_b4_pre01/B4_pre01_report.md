# Phase B4-Pre-01 独立迁移路径数据源可行性测试

2026-11-26

**结论：数据入口小试通过，正式 DFT 前仍需补齐轨迹预处理与计算参考。** 三个新材料的母晶胞与路径端点均可恢复；其中一个跨周期边界的 Li 跃迁已生成五张连续初始图像，沿用旧版 SOAP 和 MACE Activation 接口完成 CPU 测试。该路径采用直线插值，物理路径预处理与收敛仍待验证。

## 数据源与试测样本

- 索引包含 `material_id`、`edge_id`、`chemsys`、BVSE 能垒 `em`、上游划分和项目附加字段。先以历史 nebDFT2k 初始轨迹清单排除同材料 ID 和同精确元素组成集合，得到 16,155 条路径记录、2,647 个材料。这里的 `em` 是经验能垒，DFT 能量和原子力仍待计算。
- 上游 nebBVSE122k 对每条跃迁发布一个带 `X` 质心标记的超胞。试测记录有 `edge_id`、晶胞、PBC 和原子坐标，端点编码为母晶胞零基原子行和整数晶格偏移。完整路径需从母晶胞重建。BVEL13k 按 `material_id` 提供同源母晶胞。 [LiTraj 数据格式](https://github.com/AIRI-Institute/LiTraj#nebbvse122k-dataset) · [上游路径生成示例](https://github.com/AIRI-Institute/LiTraj/blob/main/notebooks/bvse_neb.ipynb) · [周期边定义](https://github.com/dembart/ions/blob/b7ef2a752bea44caa966c998d72bb145cbb55e6b/ions/edge.py)
- 本地两个 ZIP 只保存了下载前缀及另存的目录尾段。按 ZIP 目录读取本地可用字节并解压，保留原子行完整的记录。从 nebBVSE122k 的 `val` 成员前缀读到 3,906 帧，其中 464 条路径、107 个材料满足预筛，107 个均找到 BVEL13k 母晶胞。BVEL 的 `val` 和 `test` 成员可做完整 CRC 校验，`train` 成员只部分可读。三个试测母晶胞均来自 CRC 校验通过的成员。各自的质心记录完整且与母晶胞复核相符，质心压缩成员的整段 CRC 仍待补齐。BVEL 的上游 `test` 划分提供 BVSE 结构，项目保留的四个 DFT 测试材料标签未读取。
- 选样先要求晶格整倍关系、原子计数和端点行范围自洽，并限制试测超胞大小。优先使用旧版 SOAP 支持元素及已验证的母晶胞来源，覆盖不同元素体系和阴离子组，主样本优先带非零周期偏移。以大小和 edge ID 确定同优先级顺序。选样与 BVSE 结果、历史收益无关。晶格度量类别在选定后核查，正式晶体家族隔离仍待做。详见 [候选审计](candidate_audit.csv)。

## 端点恢复与周期映射

先比较母晶胞和质心超胞的晶格变换，再按 edge ID 找两个 Li 行。把目标 Li 移到编码的周期镜像，用两端中点对齐质心标记。按元素和周期距离逐一匹配所有真实原子。三例最大匹配误差在 1.0×10⁻⁸ 至 1.5×10⁻⁸ Å 之间。端点和待移除的目标 Li 在超胞内均唯一。这个误差衡量两份上游几何记录的重合精度。 [结构恢复记录](structure_recovery.csv)

主样本 `mp-1177164_1_2_0_1_0` 的偏移为 `[0,1,0]`。按该偏移恢复的跃迁长 **2.74617 Å**，直接用未修正的两端坐标相减得到 **7.21922 Å**。移除目标 Li 形成空位后，五张图像各有 63 个原子，保持相同晶胞和原子顺序。周期最短向量给出相邻迁移 Li 位移约 0.68654 Å，固定骨架原子无可检出的位移。反应坐标为 0、0.25、0.50、0.75、1。重新读取临时轨迹并显式枚举 125 组晶格平移，独立复算了位移与最近接触。五张图像最低 Li 接触距离为 **1.42724 Å**，满足历史初筛阈值。路径上的五个采样点通过几何检查，尚未评估整段通道的物理稳定性。 [逐图像质量审计](path_quality_audit.csv)

使用 A1 的 `make_extractors`、B3-A 冻结元素表和已核验的 D₀ seed-17 检查点。五张图像的几何 SOAP 为 60 维，分元素 SOAP 为 3,200 维，MACE Activation 为 256 维，与 B3-A 缓存一致，均有限且非零。这里只验证同一接口能处理新路径，正式候选仍需检查全部元素覆盖并统一路径预处理。 [特征和运行记录](feature_smoke_test.json)

## 进入正式 NEB-DFT 前的条件

1. 恢复完整上游结构成员并校验哈希或 CRC。按本次方法核对候选母晶胞、超胞和周期端点，排查近重复及同一晶体骨架。四个封存测试材料继续隔离。
2. 固定 DFT 前初始路径协议，并在少量独立材料上验证短程 BVSE 预处理。当前机器中的 ASE、NumPy、SciPy、DScribe 和 MACE 版本已记录，`ions`、`spglib` 在本次使用的环境中不可用。可以沿用本次插值做接口测试，正式比较要处理插值路径和历史 BVSE 预处理路径的差异。
3. 冻结统一 DFT 参考，包括赝势或基组、泛函、磁性和电子占据策略、空位体系设定、端点弛豫和 NEB 收敛标准。先核查新增体系的元素覆盖及与 D₀ 标签参考的相容性，再安排真正的能量与力标注、核时记录和独立评估面板。

本轮使用本机 CPU，未启动 GPU、DFT、BVSE 优化或模型训练。试测轨迹与临时测试脚本和原始数据分开保留，发布目录只有五份核对后的审计产物。
