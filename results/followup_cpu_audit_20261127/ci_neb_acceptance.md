# mp-1191903 完整 QE CI-NEB 验收表

目标是获得一条完整、可回读的 QE 迁移路径和逐原子能量、力标签。此表冻结下一次试点的验收规则。单点计算的证据覆盖端点 0、BVSE 峰区 1 和非峰区图像 2。2×2×2、50/400 Ry 为试点的计算起点。 [三图像网格验证](../phase_b4_r2/grid_three_images/report.md) · [截断能对照](../phase_b4_r2/cutoff_control/report.md)

| 环节 | 验收与记录 |
| --- | --- |
| 运行环境 | 确认实际 `neb.x` 与 `pw.x` 版本、编译器、MPI 配置、GPU 架构和赝势哈希。`pw.x` 固定几何曾通过，`neb.x` 及续算先做小规模短测。记录每图像重启文件、路径文件和写盘策略。 |
| 固定晶胞端点 | 分别弛豫 A、B，端点最大原子力 ≤0.05 eV/Å，按原子序逐项核对晶胞、周期映射、迁移 Li 和空位身份。用统一 PBE/USPP、0.10 eV 高斯展宽、中性空位、固定 1 μB 和 `conv_thr=1e-8 Ry`。若端点进入不同盆地或沿路径发生自旋分支切换，暂停并核验轨迹归属。 |
| 5 图像普通 NEB | 以周期连续的 5 图像初径启动，含两个 DFT 弛豫端点。保留一致原子序和跃迁方向，固定端点。先要求路径最大残差 ≤0.10 eV/Å，并随迭代保存各图像能量与残差。每张图都须有可核对的 SCF 收敛和周期相邻位移。 |
| CI 精化 | 从普通 NEB 已验收路径启动 CI，使用依据 DFT 路径能量识别的内部爬坡图像。验收要求最后一次有效迭代的最大路径残差 ≤0.05 eV/Å。爬坡图像应保持同一跃迁通道并可在输出中识别。路径多峰、端点接替最高能量或跨图像分支不一致时单列核验。 |
| 图像分辨率 | 用同一端点、物理协议和 CI 收敛要求比较 5 与 7 张图像，正反向能垒变化分别 ≤10 meV，迁移通道与鞍点身份对应。同一路径的中间图像沿反应坐标补点，保留原几何审计。若超阈或跃迁通道改变，暂缓放行并设计针对性补点。 |
| 弛豫后数值复核 | 共用固定的最终图像，先对端点、真实 CI 图像和一张非峰区图分别比较 2×2×2 与 3×3×3。另在最终端点和真实 CI 图像对照 50/400 与 62.5/500 Ry。每次只提高一项，再于真实 CI 图抽查 `conv_thr=1e-10 Ry`。两端点到鞍点的相对能差每次 ≤10 meV，每个比较图像的全原子力分量 RMSE ≤0.020 eV/Å，迁移 Li 力矢量差 ≤0.020 eV/Å。另记 0.010 eV/Å 力报告线和最大单原子差。 |
| 标签与预算 | 正反向能垒由同一能量口径的 CI 相对 A、B 分别求差。归档每张收敛几何上的未投影 QE 全原子力、能量、输出和 XML。另存用于评价收敛的 NEB 有效力。成本分别登记端点与数值对照、普通 NEB、CI、失败和续算的实测墙钟、MPI/线程数及 GPU 占用。 |

路径残差与用于 MACE 的全原子力是不同量。QE 手册定义了 `path_thr`、爬坡图像及端点控制。0.10/0.05 eV/Å、10 meV 和力差要求沿用本项目的工程目标。它们描述标签质检容差。后续比较训练收益时，VASP/QE 标签域和统计门槛要单独审计。 [QE NEB 输入手册](https://www.quantum-espresso.org/Doc/INPUT_NEB.html) · [项目预先记录的容差](../phase_b4_pre02/dft_protocol.md)
