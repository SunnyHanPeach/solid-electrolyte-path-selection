**42 条记录均可恢复公开端点几何，当前 0 条可纳入主评估面板。** 作者归档提供端点结构、能垒和计算元数据。主评估还需要原始完整迁移轨迹，并确认方向、几何和参考能垒一一对应。此轮核验未使用能垒数值或四个封存测试材料的标签。 [源论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12680656/) · [正式归档](https://doi.org/10.5281/zenodo.17240095)

## 来源与计算口径

B5-R 冻结的 42 条指针来自含 619 条记录的作者 GitHub 版本。以系统名称及两个完整结构对象作键，逐条唯一对到含 621 条记录的正式归档。两种数据中的数字 ID 分别记录。42 条均通过同序原子、同晶胞和周期最短位移核验。表中的 A 到 B 由公开端点顺序确定，原始论文中的正向或反向能垒归属待核。 [作者版本](https://github.com/sai-mat-group/migration-barrier-dataset/tree/9e85526f75bd836f1ca1bc6ee12e923ed25c4785) · [逐条核验](record_audit.csv)

| 正式归档中的计算方法或来源状态 | 条数 |
| --- | ---: |
| 记录为 PBE，完整轨迹与具体能垒的对应待核 | 18 |
| 明确为 PW91 或 PBEsol | 14 |

## 结构独立性

比较前移去 Li，按非 Li 骨架的匿名约化计量预筛，再作允许元素替换的周期晶胞匹配。容差为 `ltol=0.15`、`stol=0.20`、角度 5°。核验 867 个历史母晶胞、24 个 B5-R 母晶胞和完整的 278 个 canonical D₀ 训练结构。

| 对照 | 进入周期匹配的配对数 | 匿名骨架匹配对数 |
| --- | ---: | ---: |
| 历史母晶胞 | 1,049 | 74 |
| D₀ 训练结构 | 512 | 0 |
| H1 十条审查候选 | 0 | 0 |
| 其余 B5-R 候选 | 23 | 0 |
| 42 条公开记录内部 | 142 | 79 |

21 条公开记录出现历史匿名骨架相似标记，历史组中的同元素骨架匹配数为 0。公开池内部有 30 对达同元素骨架匹配，独立样本数应在完整跃迁核对后按材料或家族确定。H1 十条均在匿名计量预筛阶段分开。这里的匹配结果随计量预筛和几何容差定义变化，进入正式评估前仍需复核局部迁移环境。 [逐对结果](framework_overlap.csv) · [输入哈希与参数](manifest.json)

本地另有 SAI-MAT 作者公开的 Li₃PO₄ 与 LiCoO₂ 归档，含多图像结构或 VASP 输出。这两个精确元素体系已在历史结构清单上出现，可作为读取和标签域对照的来源。主评估候选仍以找回 18 条较近 PBE 条目的完整原始路径为先，获得后重新做方向和材料家族放行。 [SAI-MAT 原始归档](https://github.com/sai-mat-group/migration-barriers-project-public) · [主面板放行表](primary_panel_release.csv)
