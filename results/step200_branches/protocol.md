# 第 200 步共同起点四臂实验

每个种子从原八路径追加训练的第 200 步模型和 Adam 状态开始。两种子均四臂重跑。每臂续训 200 步，在第 200、201、210、250、300、400 步统一评分。使用原回放检查点的 Torch CPU/CUDA 随机状态作为所有臂的共同随机状态。Python 和 NumPy 使用同一种子的确定初始化。续训排程来自已冻结的批次文件。[排程和剂量](../step200_branch_preflight/continuation_protocol_inputs.json)

| 臂 | 第 201–400 步训练 |
| --- | --- |
| A | 等原子数 D₀ 回放 |
| B | 继续追加原八条路径，原力损失权重 |
| C | 继续追加，内部图像采用 \(w_i=1-0.75s_i\) 力损失系数 |
| D | 继续追加，内部图像按路径均匀降权，逐路径匹配 C 的曝光加权力剂量 |

\(s_i\) 是该内部图像相对较低端点的非负能量差除以相应路径内部最大值。该最大值为零时权重为 1。力剂量按每次出现时该图像占全批次原子数的比例累加。每个种子有 24 个插入批次。B、C、D 共享这些批次，端点、D₀ 与能量权重一致。B−A 比较后半段整体追加与回放的效应。C−B 和 D−B 比较降权的缓解作用。C−D 比较同剂量下的分配效应。C−A 和 D−A 判断相对回放是否有实际改善。

## 主要评价

主要指标为第 400 步历史主面板（91 个材料）的正向能垒 MAE。各模型分别在全部固定图像取最大能量减起点，单位为 meV。对同一材料先计算两臂的配对误差差，再等权平均两个种子。使用 10,000 次材料配对 Bootstrap 计算 95% 区间。区间条件于固定种子 17、29，另报两种子的点估计。

| 判定 | 预设规则 |
| --- | --- |
| 实际降低 | 区间上限低于 −0.25 meV，且两种子均为负 |
| 实际升高 | 区间下限高于 +0.25 meV，且两种子均为正 |
| 实用等效 | 整个区间与两种子均值都落在 [−0.25, +0.25] meV |
| 未决 | 其余结果 |

C−D 为预设重点对照。多个对照的区间是单项区间。历史辅助面板（88 个材料）、其他步点、有符号漂移及高能区轮廓 MAE 单列。固定峰使用 DFT 最高内部图像，同能取序号最小者。高能区为最高四分之一的内部图像，向上取整。模型换峰贡献按右侧对照模型的峰位分解，固定 DFT 峰位结果也单独保存。这些历史面板用于机制对照，新训练配方的正式确认仍需独立材料。

## 复用核验

历史 Adam 交叉的 `added-added` 是 A 的对应组。已核对两个种子的模型与 Adam 文件、Torch CPU/CUDA 随机状态、完整排程、200 次更新和六个预测文件哈希。历史硬件是 RTX 3090，原档未记录 Python/NumPy 随机状态和完整运行环境。正式实验重跑 A，两个种子在一台 GPU 上使用同一环境完成。[复用审计](reuse_audit.json)

## 运行和评分

使用仓库 `src/run_adam_cross.py --branch-protocol`。受控数据包和检查点附件单独传输。交付包内 `launch_gpu.sh` 在四臂短测通过后按种子运行八组。训练产物、日志和得分写入新目录。收齐八组后使用 `src/score_step200_branches.py` 统一评分，逐项核对实际批次、力系数、共同起点和预测哈希。
