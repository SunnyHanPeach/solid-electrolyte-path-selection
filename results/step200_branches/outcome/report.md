# 第 200 步共同起点四臂实验结果

2026-11-27。RTX 3090 完成两个种子各四组续训，共 1,600 次更新。末组于北京时间 11:31 完成，GPU 阶段约 26 分钟。各分支最大显存分配 7.31 GiB。两个种子各自的四组第 200 步预测哈希相同。已核验 48 份预测、8 个完成记录、每一步的批次顺序和施加的力系数。Linux 与 Windows 重算力系数的最大浮点差为 \(2.22\times10^{-16}\)。独立复算验证了两个面板第 400 步的 12 项能垒 MAE 对照和逐种子均值，最大差为 \(1.78\times10^{-15}\) meV。

## 实验判断

C 有一致的缓解方向，但 C−B 的区间上限为 −0.21 meV。C−D 的区间上限为 −0.20 meV，两个种子的方向不同。当前同时缺少 C 优于 D 和 C、D 实用等效的证据。保留 α=0.75 作为探索结果，现有训练配方继续作为路径筛选基准。这一轮量化的是给定八条路径和共同起点下的续训效应。相同 DFT 预算下的路径选样优势仍需独立验证。
