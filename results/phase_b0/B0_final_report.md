# Phase B0 检查点资产审计

**2026-11-26｜工程资格审计完成。** 三个同协议 D₀ 权重支持开展历史能垒分歧诊断。校准、候选净收益预测和跨家族泛化仍待验证。本轮只读原始资产，新增审计脚本与结果表。

| 问题 | 结论 |
|---|---|
| 有多少合格的独立 D₀ 检查点？ | 主组 3 个，种子 17、29、43。它们是共享初始化、不同批次顺序的独立训练。另一硬件批次 3 个使用相同的三套顺序，可单独复核。另有 9 个消融权重，按 3 个处理臂保存。 |
| 能否开展 Ensemble 分析？ | 可以回顾性检验固定初始化下的能垒预测分歧。107 材料有 595 个共同图像键及 DFT 能垒评分。三个种子覆盖的随机性有限，力分歧所需的匹配输出待确认。 |
| 有可复用的 MACE Activation 吗？ | 有。A1 保存 D₀ 种子 17 的 Li 中心表示，34 张图像中 17 张为初始轨迹。正式预训练源也已核验，其 Activation 要另行提取。 |
| 是否值得投入 NTK？ | 把它作为有条件的后续基线。先用已有能量、SOAP 和 Activation 建立可比结果。若确有必要，优先测试低维能量梯度；对 Force-aware NTK 另外核算内存与耗时。 |
| 缺少哪些资产？ | Phase 1 36 条记录有运行标记与权重哈希，缺可复核的实际权重；另缺已核验的原始 Bi 权重、可用的 Adam 状态、主组的匹配逐原子力预测和历史 NEB 实际核时。 |
| 下一阶段最经济的路线？ | 用已归档 107 材料能量做分组误差校准，并以初始轨迹复用 A1/A2 缓存。将误差检测能力和路径收益预测能力分别验证。获得批准后再启动。 |
