# H3 夜间探索 · 2026-11-29

使用本机四个低优先级 CPU 进程完成两项离线分析。分析沿用冻结候选、选样规则和 0.25 meV 实用门槛。输入只含已有公开面板比较结果、核矩阵与成本情景。时间观察器截至北京时间 08:00，现有 QE 队列独立运行。

## 哪些候选值得短测成本

在 H2 中档模型与公开网格倍率模型上，分别对三个原预算执行单候选压力测试。每次只改一条候选的成本，从 −30% 到 +30%，间隔 0.5 个百分点，跳过零点。覆盖 20 条候选和六个策略。SOAP 对照要求两臂均有可购路径，且集合不同。表中阈值为网格上首次观察到变化的偏移量。

在 133.67 小时预算下，`mp-1222483` 是两个成本模型共同识别的关键候选。H2 模型把它下调 18%，公开网格模型下调 11% 时，两臂均选 `mp-1222483` 和 `mp-23497`。两种模型对应的变动成本分别约为 **91.68** 和 **92.64 小时**。公开网格模型下，单独下调 `mp-23497` 28% 也会让两臂选成同一集合。在本轮逐路径上调范围内未出现该预算点的重合。此前共同上调整个成本向量出现重合，两项压力测试覆盖不同的误差来源。 [逐候选阈值](single_candidate_cost_thresholds.csv)

成本实测应优先判定 `mp-1222483` 的成本是否落在约 92 小时这一决策边界附近。若成本核验后两臂集合相同，该预算点不具有检验模型表示增量的判别力。

## 独立面板的精度情景

以已有外部评价的 42 个结构家族为重采样单位。对种子 17、29、43 分别中心化原效应，保留同一家族的跨种子相关性，然后加入预设的真实平均收益。每个场景抽取 768 次合成面板，每次按家族重采样 384 次。模拟判定沿用 95% 区间下限大于 0.25 meV、三个种子均值方向为正的规则。原始 `mp-753143` 的绝对和净收益分别提供两种离散度情景，未来策略差值尚未测出。

假设真实收益为 +0.50 meV，12 个家族的模拟通过率约 **39%** 和 **16%**，分别对应历史绝对收益和净收益的离散度。若真实收益为 +0.75 meV，相同规模的通过率约 **96%** 和 **48%**。12 家族适合工程试点与配对方差估计。正式样本量需要用采购策略之间的实测差值重新规划。 [全部规模和效应情景](independent_panel_scenarios.csv)
