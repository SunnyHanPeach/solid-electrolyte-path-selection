# H2 · LiTraj 家族边界与候选成本敏感性

## 独立评价资格

对 867 个母晶胞去 Li 后按匿名约化计量预筛，再作周期骨架匹配。12,743 对中有 2,424 对通过，匹配连通分量作为保守的结构组。Train、Validation、Test 的材料 ID 两两无重合，Train 与 Validation 共享 42 个结构组，Train 与 Test 共享 38 个，Validation 与 Test 共享 18 个。Validation 有 61/124 个材料、Test 有 57/136 个材料落在含有 Train 材料的结构组。D₀ 的 50 条同 ID 路径均在 Train。排除封存材料后，Validation 有 21 个材料、Test 有 11 个材料落在含有 D₀ 材料的连通组内。重用同批母晶胞的 FP-DeErr 重叠审核，已发布的 62 条外部路径通过此前的骨架筛查。

逐帧复算 241 条 Validation 和 216 条非封存 Test 路径。全部 457 条都符合 LiTraj 索引采用整条曲线最高能量减最低能量的口径。以图像 0 为零重算的正向能垒分别有 133/241、113/216 条与索引在 1 meV 内一致。四条专门封存的 Test 路径只用预先核验过的无标签清单排除。沿用既有已用材料台账，Validation 和 Test 没有额外的未用材料，本轮主评估新增放行 0 条。上述结果可用于离线回测。FP-DeErr 继续作为固定几何外部评价。[边界汇总](litraj_boundary.json) · [既有使用台账](../../experiments/phase1/absolute_gain_readiness.md)

## 24 条候选成本情景

分开计算了仅原子数、加入名义 k 点、再加入端点与 NEB 优化的成本。GPU 数值以 RTX 3090 的同材料 2×2×2、50/400 Ry 四次固定几何耗时（2,655–5,233 秒）为锚。用同材料端点与非峰区中间图像的加密网格对照估计 k 点倍率（3×3×3 相对 2×2×2 为 1.71–2.16）。未从单材料拟合跨化学体系的原子数标度。原子数指数、端点步数、路径更新、热启动折扣与重启比例均是明确的情景假设。中档采用 12 次普通 NEB 更新，参考 mp-5012 的普通 NEB 历史步数。CI 和重启的情景系数仍缺可比较的完整计时。附加的数值验收短测需按实单列。高档同时叠加多项保守假设，仅用于压力测试。

| 情景 | 24 条中每条估计求解时长的最小至最大值（小时） |
| --- | ---: |
| 低 | 8.8–45.8 |
| 中 | 41.9–240.4 |
| 高 | 247.0–1,580.9 |

这些时长是情景估算。现有计时不足以校准区间覆盖率，也不足以签发实际采购预算。最终账本还需真实的端点、普通 NEB、CI、失败与续算时长。[逐路径与分阶段明细](candidate_cost_scenarios.csv) · [标定来源](../phase_h2_cost_reuse/recorded_costs.json) · [假设清单](cost_scenario_manifest.json)

## 对采购集合的影响

基于 24 条现有候选估时，按 H1 的四条结构排除标记，在 20 条上重放六种策略。模型分歧使用 B0 的三个已核验 D₀ 模型对 120 张无标签初始图像做 CPU FP64 推理，按三种子正向能垒的样本标准差排序。SOAP 与 SOAP＋Activation 复用 B5-R 的核矩阵，依据当轮可购置路径重新执行同一 k-center 规则。预算设为 87 原子、原始 2×2×2、五图像参考案例的中档成本乘 1、2、4，具体为 66.83、133.67、267.33 小时。这些预算仅用于对照情景。

以 133.67 小时为例，低档下各策略纳入 4–6 条，中档为 1–2 条，高档没有任何候选达到该情景的准入条件。SOAP 与 SOAP＋Activation 在低档同选 6 条，中档分别选 2 条和 1 条且没有交集。成本估计会改变 Activation 对照能否构成实质不同的采购集。当前只可判断可购置集合，策略优劣仍需实际采购和独立评价。[54 项情景复算](budget_sensitivity.csv) · [模型分歧](candidate_model_disagreement.csv)

本轮仅做归档复算、结构匹配和初始几何推理。待 QE-a 的端到端日志可获得后，用它替换最敏感的情景假设，再决定是否对预算边界上的候选做短测。
