# 单路径试点后的剩余研究计划

## 1. 对照力误差与收益

用同一批项目留出几何和已保存检查点，对比净收益为正的 F–Li–Ni–O 路径与双负的 Co–Cr–Li–O 路径。比较每条路径与自身等曝光回放在第 400 步和终点的力 RMSE，同时报告纯 D₀ 作为参照。

按 DFT 相对能量把内部图像划分为最高四分之一及其他图像，端点单列。全部原子参与力误差分析。迁移 Li 需要 BVSE 初始记录和弛豫端点的最大锂位移指向同一原子。统计单位为材料，按精确化学体系配对重采样。此分析用于检验力误差与能垒收益是否同向，因果解释需要独立干预。

## 2. 复核已发现的净收益

如果决定补种子，先冻结 53 和 67。保持 Recipe A、完整路径、插入剂量与配对规则。两种子各跑路径和回放，共四次训练。需要独立更新绝对收益估计时，再补两个相应的纯 D₀ 基线。三个已完成种子的基线仅在数据、参数和顺序校验一致时复用。新种子只能检验训练随机性的影响。

另锁定可用的独立材料，优先复核这条路径相对纯 D₀ 的绝对改善。材料分层和判定规则在评分前固定。研究中用于改配方的面板记为开发或诊断数据。

## 3. 扩充不同类型的探路样本

优先从剩余候选中按已冻结的 BVSE 初始特征选一条不同化学体系且可按原子数回放的路径。用于细粒度反例的相似路径在前一结果需要解释时再加入。选择规则使用路径几何和局域环境。每条路径保留全部图像，继续记录绝对收益、净收益和材料级分布。

CPU 的 mp-5012 爬坡图像精化独立记录计算成本与收敛状态。只有通过能量与力的验收，才进入 DFT 标签库。
