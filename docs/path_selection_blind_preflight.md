## 两步验证及主要判定

1. **先验证 Activation 的增量。** 从独立候选家族和独立目标面板形成盲测。对同一候选池固定比较 SOAP 排序与 SOAP＋Activation 排序。两种方法使用一致的几何特征、成本估计和批次规则，同选记零差。单独保留 SOAP 多样性基线，它衡量组合在结构空间的覆盖，与 SOAP 单路径收益排序使用不同的决策规则。记录 BVSE、随机、MACE 集成分歧及其预计算时间。新候选和目标材料的具体清单尚待建立。
2. **再比较预算策略。** 在同一固定目标面板上报告 `MAE(B)`。为每种方法使用相同的主预算上限，中低预算点按事先冻结的顺序报告。候选排序和停止规则只能访问作决定时已知的成本信息。达到上限或任务失败时，所有已消耗资源均计入，模型使用预算内已取得的完整有效标签训练。每个预算点对实际选择的路径集合统一重训。不同策略选到相同组合时可复用已核验的同种子训练结果，策略的核时仍分别计算。

对每个预先指定的基线，报告同一目标面板上的配对差值 `ΔMAE = MAE(baseline) − MAE(selected)`，正值表示新策略更好。应用主判定要求在主预算点优于纯 D₀ 和预定的竞争基线，并单列随机选择的分布。Activation 增量的单独判定使用 SOAP 排序对照。先根据开发数据的逐材料波动确定实际效应门槛与所需独立家族数，锁定主预算点和统计口径后再揭盲。以配对种子和评价材料家族区间报告精度，以独立候选家族报告策略复现。主预算点之外的结果用于说明预算适用范围。样本支持不足时保留未决，若区间排除了所需的收益则停止推进该规则。

## 训练对照与成本

- 纯 D₀ 对应部署原模型，回答值不值得购买新标签。Path 与 Matched Replay 在相同初始权重、硬件、随机种子和训练配置下配对，匹配更新次数、有效原子和力分量数、损失权重，并记录训练耗时与装置。旧协议的纯 D₀ 为 710 步，追加组为 735 或 745 步。若主验证要求三个训练臂严格等步数，预先冻结一个统一的槽位替换日程并报告替换 D₀ 曝光的数量。若保留追加协议，等曝光结论以 Path 对 Replay 的差为依据。见 [训练预算审计](../experiments/phase1/absolute_gain_readiness.md) 和 [B2 协议](../results/b2_overnight_01/protocol.md)。
- 统一 DFT 参考设置和收敛标准。每次作业记录端点弛豫、单点与 NEB 图像迭代、失败、取消和重启。实际 DFT 核时按每次分配的 CPU 核数乘实际运行时长计，同一策略内共享端点只计一次。固定评价面板的 DFT 作为单列的共享验证成本。几何生成、模型推理和训练成本分别报告。现有 mp-5012 账本可验证记录流程，见 [一轮实际作业记录](../results/dft/mp5012_ci/cost.json)。
- 待冻结的资产包括候选及目标面板的几何来源与哈希、家族划分、查重阈值、共同成本上限、各项决策规则和种子表。首次前瞻计算前，用 CPU 在少量结构上验证端点、周期映射、整条初始路径和特征提取。公开提交只记录规则和聚合计数。四个封存材料的标签与后续主面板标签保持隔离。

本轮只读取索引、已公开的历史台账和外部来源说明。未启动 DFT、GPU 或监督学习。候选池与最终评估集均未锁定。
