# 研究命题查新复核与独立验证方案

2026-11-26

## 研究命题

给定实际 DFT 核时，能否从完整锂迁移路径中选出一组路径，让 MACE 在未见材料上的迁移能垒误差低于现有选样基线？

近期先验证一个可检验的子命题。在同样的候选池和预算下，几何 SOAP 加入 MACE Activation 后，选出的路径能否比仅用 SOAP 选出的路径带来更低的目标材料能垒 MAE？候选分数、训练收益和最终策略表现分别记录。

MACE 激活特征、NEB 主动采样、目标导向选样和数据价值估计均有先例。本轮查新保留的贡献边界是联结三项可复核结果：以完整 Li 迁移路径为采购单位，实际测量加入路径对目标能垒误差的改变，以及在同一实际 DFT 核时上限下验证选样策略。该边界仍需实验验证和持续查新。路径组合的互补性还需要联合训练实验。

## 现有证据

- B2 常规三种子共 14 条路径。按原先的 ±0.25 meV 门槛，绝对收益为 0 正、8 负、6 未决，回放调整后的净收益为 1 正、4 负、9 未决。额外种子用于复核同一路径。绝对收益引用了历史 RTX 4090 训练的纯 D₀，Path 和 Replay 来自同一批 GPU。新的主验证应让三臂训练硬件和软件环境一致。参见 [收益标签](../results/phase_b3_a/path_utility_labels.csv)、[B2 执行记录](../results/b2_overnight_01/six_hour_results/final_report.md)。
- B3-C 中，控制 SOAP 与最短接触距离后，Activation 与净收益的秩相关约为 −0.54，逐路径留一约为 −0.64 至 −0.42。切向力分歧对应约 +0.09，留一跨零。14 条路径保留为开发数据，供设定待验证方向。5 图与 7 图对应不同训练步数，仍可能混杂。参见 [B3-C 审计](../results/phase_b3_c/B3C_final_report.md)。

## 下一步实验方案

1. **冻结候选和目标材料。** 先用结构和来源元数据划定新的候选路径家族、目标评估家族。检查结构近重复、来源材料及历史开发集重叠。目标面板与候选来源、D₀ 微调集隔离，记录对基础模型预训练来源能核验的范围。形成含路径 ID、分组、初始轨迹和数据哈希的清单。冻结纳入规则、候选分数、预算和统计规则后，才揭示已有候选标签或启动新 DFT。
2. **先做固定策略的盲测。** 用预冻结的初始 NEB 特征比较 SOAP 与 SOAP＋Activation。一个简单的增量规则是在几何 SOAP 排序上加入 Activation 秩残差，控制 SOAP 和最短接触距离，方向沿用 B3-C。两项等权的规则须在揭盲前定稿。切向力分歧保留作诊断。两种策略选中同一路径时记作零增量。随机、BVSE、结构新颖性和模型驱动方法作为同池基线。模型驱动基线可用路径化 LCMD 或集成不确定性，记录从构型分数到路径分数的规则。保留纯 D₀ 作为零 DFT 开销的参照。
3. **统一评价。** 对每条进入验证的路径使用纯 D₀、Path 和 Matched Replay 三臂，固定种子和训练配方。同一路径的 Path 与 Replay 匹配曝光及更新次数。跨路径优先匹配图像数和剂量，或预先分层。目标面板上记录绝对收益 \(G_{abs}=MAE(D₀)-MAE(Path)\) 和净收益 \(G_{net}=MAE(Replay)-MAE(Path)\)。正值均代表改善。增量比较用两种策略的最终能垒 MAE 之差，联合评估策略差、相对纯 D₀ 的改进和计算量。报告各配对种子、材料家族重采样区间及逐家族敏感性，并以候选家族为策略复现单位。沿用 0.25 meV 作为小试门槛时，须在揭盲前写明各指标的通过条件。维持现有数据时优先扩大独立候选家族，避免把材料、种子当成候选路径数量。
4. **区分离线盲测和实际预算验证。** 现成标签可以支持盲测，成本缺失时只能比较预先定义的代理成本或标签数。实际 DFT 核时逐作业计算分配核数乘运行时长，计入端点弛豫、NEB、失败和重启，同一策略内共享端点只记一次。正式比较在统一预算上限下报告实际花费和最终能垒 MAE，允许保留预算。若独立盲测未显示 Activation 增益，优先保留 SOAP 简单基线。若所有策略均未达到纯 D₀ 的绝对收益要求，当前预算下保留零成本方案。
5. **将组合效应留给独立对照。** 有充分的单路径证据后，可比较 \(R_P+R_Q\)、\(P+R_Q\)、\(R_P+Q\)、\(P+Q\) 四个等曝光、等步数训练臂，统一用下游得分 \(U=-MAE\)。交互为 \(U(P+Q)-U(P+R_Q)-U(R_P+Q)+U(R_P+R_Q)\)。几何相似度可以帮助挑选两条路径，互补性估计以实际联合训练为依据。

本次提交冻结的是证据记录和待确认的验证规则。候选清单、目标材料清单、预算与执行门槛仍需在正式揭盲前单独冻结。本轮未启动训练或 DFT，未读取新封存标签。
